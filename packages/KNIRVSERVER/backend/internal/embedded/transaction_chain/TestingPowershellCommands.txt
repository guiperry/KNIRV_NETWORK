**PowerShell Equivalents Using `Invoke-WebRequest`:**

1.  **Get a Session ID (QR Code Simulation):**
    *   PowerShell command:
        ```powershell
        $response = Invoke-WebRequest -Uri "http://localhost:8081/auth/qr" -Method Get
        $responseJson = ConvertFrom-Json $response.Content
        Write-Host "Session ID: $($responseJson.session_id)"
		Write-Host "Wallet Address: $($responseJson.wallet_address)"
        ```
    *   **Explanation:**
        *   `Invoke-WebRequest -Uri "http://localhost:8081/auth/qr" -Method Get`: This makes a `GET` request to the `/auth/qr` endpoint.
        *   `$response = ...`: Stores the response in a variable named `$response`.
        *   `$responseJson = ConvertFrom-Json $response.Content`: This uses `ConvertFrom-Json` to parse the JSON content from the HTTP response into a PowerShell object.
        *   `Write-Host ...`: This will display the result, including the `session_id` and the `wallet_address`.
    * **Notes**: Copy the generated session id, and the client wallet for the following steps.

2.  **Simulate Wallet Signature:**
    *   PowerShell command:
        ```powershell
        $body = @{
          "signature"    = "mocked_signature_from_opteq_wallet_application"
          "wallet_address" = "0x0"
          "session_id"   = "session_id_from_step_one" #Replace with the value from above step
        } | ConvertTo-Json

        $response = Invoke-WebRequest -Uri "http://localhost:8081/auth/wallet_signature" -Method Post -ContentType "application/json" -Body $body
        $responseJson = ConvertFrom-Json $response.Content
        Write-Host "Token: $($responseJson.token)"
		Write-Host "Message: $($responseJson.message)"
		Write-Host "Check cookies: $($response.Headers.Set-Cookie)"
        ```
    *   **Explanation:**
        *   `$body = @{ ... } | ConvertTo-Json`: Creates a PowerShell object with the JSON data and converts it into a JSON string. **Make sure to replace the `session_id` and the `signature` value with data from the previous step.**
        *   `Invoke-WebRequest -Uri ... -Method Post -ContentType "application/json" -Body $body`: Sends a `POST` request to `/auth/wallet_signature` with the JSON data in the body.
		* The Set-Cookie field in the headers is what sets and provides a value that we will need in the following requests.
        *    `$responseJson = ConvertFrom-Json $response.Content`: Parses JSON from the response to a json object for easier use.
        *    `Write-Host ...`: Prints the token and message obtained as response from the request.
     * **Notes**: Copy the generated token and any Set-Cookie header for following steps, if needed.

3.  **Test user info**:
   * Using powershell we can now retrieve the user info data as well as checking if the server is properly set up to authorize requests that require a token.

```powershell
$token = "your_session_token_here" # Replace with the token received
$headers = @{
    "Authorization" = "Bearer $token"
}
$response = Invoke-WebRequest -Uri "http://localhost:8081/user_info" -Headers $headers -Method Get
$responseJson = ConvertFrom-Json $response.Content
Write-Host "User Info: $($responseJson | ConvertTo-Json -Compress)"

```
	* **Explanation:**
    *   `$headers = @{ "Authorization" = "Bearer $token" }`:  Creates a hashtable of the `Authorization` header with Bearer token data.
	* `Invoke-WebRequest -Uri ... -Headers $headers -Method Get`: Creates a HTTP Get request using the provided headers.
	* `$responseJson = ConvertFrom-Json $response.Content`: Parse returned json data into a usable object
    *   `Write-Host ...`:  Prints the response as json output for easy analysis.
