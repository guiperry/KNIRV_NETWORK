# KNIRV Integration Test Reports

This directory contains validation reports and documentation for the KNIRV D-TEN integration testing suite.

## Overview

The integration testing suite validates the complete KNIRV ecosystem according to Month 6 specifications in the D-TEN implementation plan. This includes:

- **Basic Integration Tests**: Core functionality validation for each component
- **Cross-Component Validation**: Inter-component communication and data flow
- **Performance Testing**: Load testing and performance benchmarking
- **End-to-End Workflows**: Complete user journey validation

## Report Types

### 1. Test Execution Reports
- **File Pattern**: `test-results-YYYYMMDD-HHMMSS.json`
- **Content**: Detailed test execution results in JSON format
- **Generated By**: `go test -json` output during test runs

### 2. Performance Reports
- **File Pattern**: `performance-report-YYYYMMDD-HHMMSS.json`
- **Content**: Performance metrics, latency measurements, throughput data
- **Generated By**: Performance test suite

### 3. Cross-Component Validation Reports
- **File Pattern**: `cross-component-validation-YYYYMMDD-HHMMSS.json`
- **Content**: Integration point validation results
- **Generated By**: Cross-component test suite

### 4. HTML Summary Reports
- **File Pattern**: `test-report-YYYYMMDD-HHMMSS.html`
- **Content**: Human-readable test summary with visualizations
- **Generated By**: Test runner script

### 5. Cleanup Reports
- **File Pattern**: `cleanup-report-YYYYMMDD-HHMMSS.txt`
- **Content**: Test environment cleanup status and verification
- **Generated By**: Teardown script

## Running Tests

### Quick Start
```bash
# Run all tests with setup and teardown
./integration-tests/config/run-tests.sh

# Run specific test suite
./integration-tests/config/run-tests.sh performance

# Run with custom pattern
./integration-tests/config/run-tests.sh --pattern TestLLM
```

### Manual Setup
```bash
# Setup test environment
./integration-tests/config/setup.sh

# Run tests manually
cd integration-tests
go test -v ./...

# Cleanup
./integration-tests/config/teardown.sh
```

## Troubleshooting

### Common Issues

1. **Port Conflicts**
   - **Symptom**: Services fail to start
   - **Solution**: Use `--clean-start` flag or manually kill processes on ports 8080-8086

2. **Test Timeouts**
   - **Symptom**: Tests fail with timeout errors
   - **Solution**: Increase timeout with `--timeout 900s` or check service health

3. **Database Conflicts**
   - **Symptom**: Data inconsistency between test runs
   - **Solution**: Ensure proper cleanup between tests or use `--clean-start`

4. **Network Issues**
   - **Symptom**: Cross-component communication failures
   - **Solution**: Verify all services are running and accessible

### Debug Mode
```bash
# Run with verbose output
./integration-tests/config/run-tests.sh --verbose

# Check service logs
tail -f integration-tests/logs/*.log

# Manual service health check
curl http://localhost:8080/health
curl http://localhost:8081/health
# ... etc for all services
```
