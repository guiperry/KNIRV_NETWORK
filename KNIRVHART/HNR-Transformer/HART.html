Systemic Risks & Mitigation Strategies

Data Normalization Drift

Standard scaling fails during traffic bursts, blinding the model to real anomalies.

Mitigation: Implement robust Adaptive Z-Score Normalization on the Host CPU.

False Positive Cascades

Inaccurate alerts can induce real network instability through unnecessary automated actions.

Mitigation: Output a confidence score with each command; only act above a dynamic threshold.

Topology Change Blindness

A model trained on a static network map becomes instantly obsolete when topology changes.

Mitigation: Regularly push a Topology Context Vector into the HART input stream.
