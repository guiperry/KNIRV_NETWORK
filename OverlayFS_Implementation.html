Architecture

Phase 2 · OverlayFS Layer

New file: packages/KNIRVSERVER/backend/internal/services/dve/overlayfs.go

Workspace Directory Layout

/var/lib/knirvserver/
├── busybox-rootfs/          ← read-only lower layer (shared, ~5MB)
│   ├── bin/                 ← busybox symlinks
│   ├── etc/
│   ├── tmp/
│   └── usr/
└── workspaces/
    └── {dveID}/
        ├── upper/           ← per-DVE CoW writable layer
        ├── work/            ← OverlayFS internal (must be same FS as upper)
        └── merged/          ← DVE sees this as its root /

Core Implementation

package dve

import (
    "fmt"
    "os"
    "path/filepath"
    "syscall"

    "golang.org/x/sys/unix"
)

type OverlayWorkspace struct {
    DVEID      string
    LowerDir   string // busybox-rootfs (shared, read-only)
    UpperDir   string // per-DVE writable CoW layer
    WorkDir    string // OverlayFS internal scratch
    MergedDir  string // DVE's visible root
    mounted    bool
}

// NewOverlayWorkspace allocates directory structure for a DVE.
// Does NOT mount — call Mount() inside the target namespace.
func NewOverlayWorkspace(workspaceRoot, busyboxRootfs, dveID string) (*OverlayWorkspace, error) {
    base := filepath.Join(workspaceRoot, dveID)
    dirs := []string{
        filepath.Join(base, "upper"),
        filepath.Join(base, "work"),
        filepath.Join(base, "merged"),
    }
    for _, d := range dirs {
        if err := os.MkdirAll(d, 0755); err != nil {
            return nil, fmt.Errorf("mkdir %s: %w", d, err)
        }
    }
    return &OverlayWorkspace{
        DVEID:     dveID,
        LowerDir:  busyboxRootfs,
        UpperDir:  filepath.Join(base, "upper"),
        WorkDir:   filepath.Join(base, "work"),
        MergedDir: filepath.Join(base, "merged"),
    }, nil
}

// Mount performs the overlayfs mount.
// Must be called from within a mount namespace (see namespace.go).
func (w *OverlayWorkspace) Mount() error {
    opts := fmt.Sprintf(
        "lowerdir=%s,upperdir=%s,workdir=%s",
        w.LowerDir, w.UpperDir, w.WorkDir,
    )
    err := unix.Mount("overlay", w.MergedDir, "overlay", 0, opts)
    if err != nil {
        // Fallback: fuse-overlayfs for rootless environments without kernel overlay support
        err = w.mountFuseOverlay(opts)
    }
    if err != nil {
        return fmt.Errorf("overlayfs mount failed: %w", err)
    }
    w.mounted = true
    return nil
}

// Unmount tears down the overlayfs mount and does NOT delete upper layer data.
func (w *OverlayWorkspace) Unmount() error {
    if !w.mounted {
        return nil
    }
    if err := unix.Unmount(w.MergedDir, unix.MNT_DETACH); err != nil {
        return fmt.Errorf("unmount %s: %w", w.MergedDir, err)
    }
    w.mounted = false
    return nil
}

// Destroy unmounts and removes all per-DVE directories (upper/work/merged).
// Call when the DVE is permanently terminated, not just suspended.
func (w *OverlayWorkspace) Destroy() error {
    w.Unmount()
    base := filepath.Dir(w.UpperDir)
    return os.RemoveAll(base)
}

func (w *OverlayWorkspace) mountFuseOverlay(opts string) error {
    // fuse-overlayfs binary path is configurable (see DVEConfig.FuseOverlayFSBin)
    cmd := exec.Command("fuse-overlayfs", "-o", opts, w.MergedDir)
    out, err := cmd.CombinedOutput()
    if err != nil {
        return fmt.Errorf("fuse-overlayfs: %w — %s", err, out)
    }
    return nil
}

Phase 3 · Linux User Namespace Isolation

New file: packages/KNIRVSERVER/backend/internal/services/dve/namespace.go

Each DVE workspace runs in its own user + mount namespace. The host process calls os/exec with SysProcAttr to clone namespaces before running the mount. This requires no root privileges on Linux ≥ 3.18.

package dve

import (
    "os/exec"
    "syscall"
)

type DVENamespace struct {
    Workspace  *OverlayWorkspace
    UID, GID   int
    cmd        *exec.Cmd
}

// SpawnNamespaced starts a long-running helper process inside new
// user + mount namespaces, then performs the OverlayFS mount from within.
// The helper process stays alive for the DVE lifetime; killing it
// releases the namespace and triggers lazy unmount.
func SpawnNamespaced(ws *OverlayWorkspace, uid, gid int, fuseOverlayFSBin string) (*DVENamespace, error) {
    // The namespace_helper binary is a minimal Go binary (embedded) that:
    // 1. Receives the overlay mount options on stdin
    // 2. Performs unix.Mount("overlay", ...) inside its own mount namespace
    // 3. Blocks until stdin closes (DVE teardown)
    cmd := exec.Command("/proc/self/exe", "--dve-ns-helper")
    cmd.SysProcAttr = &syscall.SysProcAttr{
        Cloneflags: syscall.CLONE_NEWUSER | syscall.CLONE_NEWNS,
        UidMappings: []syscall.SysProcIDMap{
            {ContainerID: 0, HostID: uid, Size: 65536},
        },
        GidMappings: []syscall.SysProcIDMap{
            {ContainerID: 0, HostID: gid, Size: 65536},
        },
    }
    // Pass workspace paths to helper via env
    cmd.Env = []string{
        "DVE_LOWER="  + ws.LowerDir,
        "DVE_UPPER="  + ws.UpperDir,
        "DVE_WORK="   + ws.WorkDir,
        "DVE_MERGED=" + ws.MergedDir,
        "DVE_FUSE_BIN=" + fuseOverlayFSBin,
    }
    if err := cmd.Start(); err != nil {
        return nil, fmt.Errorf("spawn ns helper: %w", err)
    }
    ws.mounted = true
    return &DVENamespace{Workspace: ws, UID: uid, GID: gid, cmd: cmd}, nil
}

// Teardown sends SIGTERM to the helper, which causes lazy unmount of merged/.
func (n *DVENamespace) Teardown() error {
    if n.cmd != nil && n.cmd.Process != nil {
        n.cmd.Process.Signal(syscall.SIGTERM)
        n.cmd.Wait()
    }
    return nil
}
Namespace Helper Pattern

The --dve-ns-helper flag causes main.go to branch into a minimal helper loop at startup (before cobra/viper init). This is the same pattern used by runc and rootlesskit — the process re-executes itself into the target namespace rather than requiring a separate binary.

Phase 4 · BusyBox Rootfs Setup

New file: packages/KNIRVSERVER/backend/internal/services/dve/busybox.go

The BusyBox rootfs is a one-time setup that creates the shared lower OverlayFS layer. All DVE workspaces share this layer — it is never written to at runtime.

Rootfs Structure

/var/lib/knirvserver/busybox-rootfs/
├── bin/
│   ├── busybox             ← static binary (~1.4MB, no libc deps)
│   ├── sh -> busybox
│   ├── ls -> busybox
│   ├── cat -> busybox
│   ├── cp -> busybox
│   ├── grep -> busybox
│   ├── curl -> busybox     ← or wget
│   ├── tar -> busybox
│   ├── gzip -> busybox
│   └── ...                 ← ~400 applets via symlink
├── etc/
│   ├── passwd              ← dve:x:0:0:DVE User:/workspace:/bin/sh
│   └── group
├── tmp/                    ← writable via upper layer
├── workspace/              ← DVE working directory mount point
└── proc/                   ← proc bind-mount point

Bootstrap Logic

package dve

// EnsureBusyBoxRootfs checks if the shared rootfs exists and is valid.
// Downloads + extracts busybox-static if missing.
// This runs once at DVEService startup, not per-workspace.
func EnsureBusyBoxRootfs(rootfsPath string, cfg DVEConfig) error {
    marker := filepath.Join(rootfsPath, ".knirvdve-ready")
    if _, err := os.Stat(marker); err == nil {
        return nil // already bootstrapped
    }
    log.Printf("DVEService: bootstrapping BusyBox rootfs at %s", rootfsPath)

    switch cfg.BusyBoxSource {
    case "embedded":
        return extractEmbeddedBusyBox(rootfsPath)
    case "package":
        return installViaDpkg(rootfsPath) // apt-get busybox-static
    case "download":
        return downloadBusyBox(rootfsPath, cfg.BusyBoxVersion)
    default:
        return fmt.Errorf("unknown busybox_source: %s", cfg.BusyBoxSource)
    }
}

// extractEmbeddedBusyBox uses the //go:embed busybox-static binary
// bundled at build time — zero external dependencies, works air-gapped.
func extractEmbeddedBusyBox(rootfsPath string) error {
    //go:embed bin/busybox-static
    var embeddedBusybox []byte  // added to package at build time
    binPath := filepath.Join(rootfsPath, "bin", "busybox")
    if err := os.MkdirAll(filepath.Dir(binPath), 0755); err != nil {
        return err
    }
    if err := os.WriteFile(binPath, embeddedBusybox, 0755); err != nil {
        return err
    }
    return createRootfsSymlinks(rootfsPath)
}

// createRootfsSymlinks creates the standard BusyBox applet symlinks
// and the minimal /etc/passwd, /workspace, /tmp directories.
func createRootfsSymlinks(rootfsPath string) error {
    applets := []string{"sh", "ls", "cat", "cp", "mv", "rm", "mkdir",
        "grep", "find", "tar", "gzip", "wget", "curl", "env", "echo", "test",
        "chmod", "chown", "head", "tail", "sort", "awk", "sed", "wc", "ps"}
    binDir := filepath.Join(rootfsPath, "bin")
    for _, a := range applets {
        os.Symlink("busybox", filepath.Join(binDir, a))
    }
    for _, d := range []string{"etc", "tmp", "workspace", "proc"} {
        os.MkdirAll(filepath.Join(rootfsPath, d), 0755)
    }
    os.WriteFile(filepath.Join(rootfsPath, "etc", "passwd"),
        []byte("dve:x:0:0:DVE Workspace:/workspace:/bin/sh\n"), 0644)
    os.WriteFile(filepath.Join(rootfsPath, ".knirvdve-ready"), []byte("1"), 0644)
    return nil
}

Phase 5 · Wazero Skill Executor

New file: packages/KNIRVSERVER/backend/internal/services/dve/wazero_executor.go

Wazero is a pure-Go WASM runtime (no CGO). Skill validation WASM modules run here, with their WASI filesystem root mapped to the DVE's merged/ directory. No untrusted code reaches the host syscall surface.

Dependencies to add to go.mod

require (
    github.com/tetratelabs/wazero v1.7.3
)

Implementation

package dve

import (
    "context"
    "fmt"
    "time"

    "github.com/tetratelabs/wazero"
    "github.com/tetratelabs/wazero/imports/wasi_snapshot_preview1"
    "github.com/tetratelabs/wazero/sys"
)

type SkillExecConfig struct {
    WASMBytes      []byte        // compiled skill WASM module
    WorkspaceRoot  string        // DVE merged/ directory (WASI FS root)
    Args           []string      // argv[1:]
    Env            []string      // key=value pairs
    Timeout        time.Duration  // max wall-clock time
    MaxMemoryBytes uint32        // WASM linear memory limit
}

type SkillExecResult struct {
    ExitCode uint32
    Stdout   string
    Stderr   string
    Elapsed  time.Duration
}

// ExecuteSkillWASM runs a skill WASM module in a Wazero sandbox.
// The module's filesystem is confined to workspace.MergedDir.
// Host network and clock are available only if cfg allows them.
func ExecuteSkillWASM(ctx context.Context, cfg SkillExecConfig) (SkillExecResult, error) {
    var stdout, stderr strings.Builder
    start := time.Now()

    ctx, cancel := context.WithTimeout(ctx, cfg.Timeout)
    defer cancel()

    rtCfg := wazero.NewRuntimeConfig().
        WithMemoryLimitPages(cfg.MaxMemoryBytes / 65536).
        WithCloseOnContextDone(true)

    rt := wazero.NewRuntimeWithConfig(ctx, rtCfg)
    defer rt.Close(ctx)

    wasi_snapshot_preview1.MustInstantiate(ctx, rt)

    fsCfg := wazero.NewFSConfig().
        WithDirMount(cfg.WorkspaceRoot, "/"). // DVE root = skill's /
        WithReadOnlyDirMount(cfg.WorkspaceRoot+"/bin", "/bin") // BusyBox applets

    modCfg := wazero.NewModuleConfig().
        WithStdout(&stdout).
        WithStderr(&stderr).
        WithFSConfig(fsCfg).
        WithArgs(append([]string{"skill"}, cfg.Args...)...).
        WithEnv("KNIRV_DVE", "1").
        WithSysNanosleep(). // allow sleep() calls
        WithSysWalltime()

    for _, e := range cfg.Env {
        kv := strings.SplitN(e, "=", 2)
        if len(kv) == 2 {
            modCfg = modCfg.WithEnv(kv[0], kv[1])
        }
    }

    compiled, err := rt.CompileModule(ctx, cfg.WASMBytes)
    if err != nil {
        return SkillExecResult{}, fmt.Errorf("compile wasm: %w", err)
    }

    _, err = rt.InstantiateModule(ctx, compiled, modCfg)
    exitCode := uint32(0)
    if err != nil {
        if exitErr, ok := err.(*sys.ExitError); ok {
            exitCode = exitErr.ExitCode()
        } else {
            return SkillExecResult{}, fmt.Errorf("run wasm: %w", err)
        }
    }

    return SkillExecResult{
        ExitCode: exitCode,
        Stdout:   stdout.String(),
        Stderr:   stderr.String(),
        Elapsed:  time.Since(start),
    }, nil
}
Skill WASM Compilation Path

Skills submitted to KNIRVCHAIN as skill.md describe behavior in markdown. A build step (separate from DVE execution) compiles the skill's associated Go/Rust source into a WASM binary stored on IPFS. The DVE fetches this WASM blob by IPFS CID at validation time. The compilation toolchain is not in scope for this plan — it is handled by the existing KNIRVSERVER plugin system.

func (s *DVEService) createVirtualDVEAsync(env *DVEEnvironment) {
    // 1. Allocate overlay workspace directories
    ws, err := NewOverlayWorkspace(s.config.WorkspaceRoot, s.config.BusyBoxRootfsPath, env.ID)
    if err != nil {
        env.Status = EnvStatusError
        log.Printf("DVEService: overlay workspace alloc failed for %s: %v", env.ID, err)
        return
    }

    // 2. Spawn user+mount namespace and mount OverlayFS within it
    ns, err := SpawnNamespaced(ws, os.Getuid(), os.Getgid(), s.config.FuseOverlayFSBin)
    if err != nil {
        env.Status = EnvStatusError
        log.Printf("DVEService: namespace spawn failed for %s: %v", env.ID, err)
        return
    }

    // 3. Write DVE identity files into the upper (writable) layer
    identityDir := filepath.Join(ws.UpperDir, "workspace")
    os.MkdirAll(identityDir, 0755)
    os.WriteFile(filepath.Join(identityDir, "IDENTITY.md"),
        []byte(s.generateDVEIdentity(env)), 0644)
    os.WriteFile(filepath.Join(identityDir, "AGENT.md"),
        []byte(s.generateAgentInstructions(env)), 0644)

    // 4. Register namespace handle for teardown
    s.mu.Lock()
    s.namespaces[env.ID] = ns
    env.Status   = EnvStatusRunning
    env.WorkspacePath = ws.MergedDir // agents see merged/ as their root
    env.ContainerID   = fmt.Sprintf("ovl-%s", env.ID)
    s.mu.Unlock()

    log.Printf("DVEService: workspace %s ready at %s (<10ms, OverlayFS)", env.ID, ws.MergedDir)
}

Path security invariant

Every workspace FS handler resolves the requested path with filepath.EvalSymlinks then calls filepath.Rel(ws.MergedDir, resolved). If the relative result starts with ".." or equals "..", the request is rejected with 403. The BusyBox rootfs path is also explicitly excluded from write operations regardless of the resolved path.

type WorkspaceFSHandlers struct {
    dveService interface {
        GetWorkspace(dveID string) (*dve.OverlayWorkspace, error)
    }
    explorerCfg ExplorerConfig
}

type ExplorerConfig struct {
    MaxFileSizeBytes  int64  // cap for inline cat/preview
    AllowUpload       bool
    AllowDelete       bool
    HiddenPathPrefixes []string // paths to omit from listings (e.g. "work/")
    ShowLayerOrigin   bool   // annotate files with "upper" or "lower"
}

// workspaceRoot validates dveID, resolves ws.MergedDir, and checks path safety.
func (h *WorkspaceFSHandlers) workspaceRoot(dveID, reqPath string) (string, string, error) {
    ws, err := h.dveService.GetWorkspace(dveID)
    if err != nil {
        return "", "", fmt.Errorf("workspace not found: %w", err)
    }
    // Resolve symlinks to prevent traversal via symlink chains
    clean := filepath.Join(ws.MergedDir, filepath.Clean("/"+reqPath))
    resolved, err := filepath.EvalSymlinks(clean)
    if err != nil {
        // Path may not exist yet — use Clean without EvalSymlinks for writes
        resolved = clean
    }
    rel, err := filepath.Rel(ws.MergedDir, resolved)
    if err != nil || strings.HasPrefix(rel, "..") {
        return "", "", fmt.Errorf("path outside workspace")
    }
    for _, hidden := range h.explorerCfg.HiddenPathPrefixes {
        if strings.HasPrefix(rel, hidden) {
            return "", "", fmt.Errorf("path not accessible")
        }
    }
    return ws.MergedDir, resolved, nil
}

Layer detection in ListDir

func (h *WorkspaceFSHandlers) layerOf(ws *dve.OverlayWorkspace, resolvedPath string) string {
    // A file exists in the upper layer only if its path under UpperDir exists on disk.
    // Files that exist ONLY in LowerDir are read-only BusyBox layer.
    rel, _ := filepath.Rel(ws.MergedDir, resolvedPath)
    upperPath := filepath.Join(ws.UpperDir, rel)
    if _, err := os.Lstat(upperPath); err == nil {
        return "upper"
    }
    return "lower"
}

const DVE_ID = '{{ .DVEID }}';
const ALLOW_WRITE = {{ .ExplorerAllowWrite }}; // injected by Go handler based on auth
let currentFile = null;

async function loadDir(path) {
    const res = await fetch(`/api/dve/${DVE_ID}/workspace/ls?path=${encodeURIComponent(path)}`);
    if (!res.ok) return;
    const data = await res.json();
    renderTree(document.getElementById('treeRoot'), path, data.entries);
}

function renderTree(container, basePath, entries) {
    container.innerHTML = '';
    // Sort: directories first, then files
    entries.sort((a, b) => (b.is_dir - a.is_dir) || a.name.localeCompare(b.name));
    entries.forEach(entry => {
        const row = document.createElement('div');
        row.className = 'tree-row' + (entry.is_dir ? ' tree-dir' : ' tree-file');
        row.dataset.path = basePath.replace(/\/+$/, '') + '/' + entry.name;
        row.dataset.layer = entry.layer;
        const icon = entry.is_dir ? '📁' : fileIcon(entry.name, entry.mime);
        const layerBadge = entry.layer === 'lower'
            ? '<span class="layer-lower">🔒</span>'
            : '<span class="layer-upper">✏</span>';
        row.innerHTML = `${icon} <span class="tree-name">${entry.name}</span> ${layerBadge}`;
        if (entry.is_dir) {
            row.onclick = (e) => { e.stopPropagation(); toggleDir(row); };
        } else {
            row.onclick = () => openFile(row.dataset.path, entry);
        }
        container.appendChild(row);
    });
}

async function openFile(path, entry) {
    currentFile = { path, entry };
    document.getElementById('viewerFileName').textContent = path;
    document.getElementById('viewerLayer').textContent =
        entry.layer === 'upper' ? 'DVE Layer (writable)' : 'BusyBox Layer (read-only)';
    document.getElementById('viewerLayer').className =
        'layer-badge layer-' + entry.layer;
    document.getElementById('viewerSize').textContent = humanSize(entry.size);
    const viewerPre = document.getElementById('viewerPre');
    viewerPre.textContent = 'Loading…';
    document.getElementById('viewerPlaceholder').style.display = 'none';
    document.getElementById('viewerContent').style.display = 'flex';

}

async function toggleDir(row) {
    const existing = row.nextElementSibling;
    if (existing && existing.classList.contains('tree-children')) {
        existing.remove(); row.classList.remove('open'); return;
    }
    row.classList.add('open');
    const children = document.createElement('div');
    children.className = 'tree-children';
    row.after(children);
    const res = await fetch(`/api/dve/${DVE_ID}/workspace/ls?path=${encodeURIComponent(row.dataset.path)}`);
    if (res.ok) { const d = await res.json(); renderTree(children, row.dataset.path, d.entries); }
}

Open Questions

These are all exposed as runtime-configurable settings in the frontend panel below. Default answers are shown — change them in the UI without redeploying.

#QuestionDefaultImpact
Q1 BusyBox binary source? embedded Embedded = largest binary but fully air-gapped. package = smaller binary, requires apt on host. download = fetched at first run.
Q2 Use kernel OverlayFS or fuse-overlayfs? kernel (auto-fallback to fuse) Kernel OverlayFS is faster but requires user namespace support. fuse-overlayfs works everywhere rootless.
Q3 Network isolation per DVE workspace? false Enabling adds a network namespace per DVE. Requires slirp4netns for internet access from within the workspace.
Q4 Skill WASM execution timeout? 120s Too short = false-fail for complex skills. Too long = resource exhaustion under load.
Q5 Skill WASM memory limit? 512MB Wazero enforces via linear memory page count. Must be enough for skill + data, not so large it crowds concurrent executions.
Q6 Max concurrent WASM executions? 10 Each WASM executor is goroutine-backed with its own runtime. Higher = more throughput, more memory. Semaphore-gated.
Q7 Workspace upper-layer retention after DVE terminates? 48 hours Retaining upper layer allows workspace resume on reconnect. Set to 0 for immediate cleanup on terminate.
Q8 fuse-overlayfs binary path? fuse-overlayfs (PATH lookup) Only relevant when kernel OverlayFS unavailable. Set to absolute path if not in PATH on the host.
Q9 Show BusyBox system directories in the file explorer? false (hide /proc /sys /dev /run) Hiding reduces noise for end-users. Enabling is useful for DVE debugging. Controlled via ExplorerConfig.HideSystemDirs.
Q10 Maximum file size for inline preview in the explorer? 512 KB Files larger than the limit show a "Download" button instead of inlining content. Prevents browser memory issues with large binaries.
Q11 Allow write operations (upload / delete) from the file explorer? false for read-only public page; true for authenticated sessions ExplorerConfig.AllowWrite. Upload/delete are always token-gated regardless. Read-only is safer for shared DVE pages.
Q12 Show OverlayFS layer-origin badges (🔒 BusyBox / ✏ DVE upper)? true Informative for developers; may confuse end-users who don't know about OverlayFS layers. Toggle via ExplorerConfig.ShowLayerBadges.
Q13 Enable the file explorer tab by default when DVE page loads? true when workspace is active; false when workspace is stopped If WorkspaceActive=false, the explorer renders a "workspace stopped" message instead of the tree. The tab is always visible but gated on workspace state.
