## Design Guidelines

### Brand Colors
- Primary Blue: #2b56f5
- Secondary Blue: #00c0fa
- Dark Background: #1a1a2e
- Light Text: #ffffff
- Accent Purple: #6c5ce7

### Typography
- Primary Font: Modern sans-serif (Roboto, Inter, or similar)
- Heading Weight: 600-700
- Body Weight: 400-500

### Content Elements
- KNIRV D-TEN logo
- "Decentralized Trusted Execution Network" tagline
- Key features (12 sovereign layers, self-improving AI, etc.)
- Call-to-action appropriate for each platform
- Consistent visual hierarchy

### Platform-Specific Considerations

#### Facebook/LinkedIn
- Professional, clean design
- Focus on business value proposition
- Include website URL
- Emphasize enterprise benefits

#### Twitter/X
- Bold, eye-catching design
- Include relevant hashtags in description
- Emphasize innovation and technology
- Use emojis strategically

#### YouTube
- Video-focused thumbnail design
- Clear, readable text even at small sizes
- Play button or video indicator
- Compelling visual hook

#### GitHub
- Developer-focused messaging
- Code/technical elements
- Open source emphasis
- Star/fork call-to-action

#### Medium
- Article-style header
- Professional, editorial design
- Thought leadership focus
- Clean, readable layout

#### Discord
- Community-focused design
- Gaming/social elements
- Vibrant, engaging colors
- Server invite emphasis

## Usage

These images are automatically referenced in the HTML meta tags for social sharing. When users share KNIRV D-TEN content on social media, the appropriate platform-specific image will be displayed.

## File Naming Convention

- Use lowercase with hyphens
- Include platform name
- Use descriptive suffixes when needed
- Example: `twitter-card-announcement.png`

## Optimization

All images should be:
- Compressed for web delivery
- Optimized for fast loading
- High quality for retina displays
- Accessible with proper alt text
