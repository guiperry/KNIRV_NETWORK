1. Executive Summary

The 2_DATA_ENCODER stage of the KNIRVHASHER pipeline stalls during the NRV encoder phase because nrv_encoder.go contains only a placeholder Run() method (lines 38–43). The Apache Flight stream that should read .arrow batches from the miner_processed KNIRVBASE collection was never implemented. Additionally, there is no readiness contract between 1_DATA_MINER and 2_DATA_ENCODER, so the encoder attempts to read from a collection that may not yet contain data.

This plan specifies four targeted fixes:

  1. Flight stream client — replace the stub with full streaming logic
  2. Readiness probes — poll the miner_processed collection before consuming
  3. Exponential backoff/retry — prevent aggressive blocking on empty streams
  4. Pipeline handshake — add atomic signals so the miner signals readiness
Impact: Without these fixes the encoder silently returns nil (the placeholder body at line 42), producing zero .nrv brackets. Downstream 3_DATA_TRAINER receives empty input, causing the entire pipeline to produce no trained seeds.

3. Problem Statement

When the 2_DATA_ENCODER pipeline stage runs, NRVEncoder.Run() executes the placeholder body at nrv_encoder.go:41–42: 
func (e *NRVEncoder) Run(ctx context.Context) error {
    // TODO: Implement Flight stream reading from knirvbase
    // This is a placeholder implementation
    _ = memory.NewGoAllocator()
    return nil                                   // ← NEVER STREAMS DATA
}

This produces zero .nrv brackets, resulting in an empty encoder_output collection. The 3_DATA_TRAINER stage then processes nothing, and the pipeline completes without any trained seeds. The user sees a “successful” run with no actionable output.

4. Root Cause Analysis

4.1 Unimplemented Data Ingestion

Primary cause. The Run() method (lines 38–43) was left as a TODO placeholder. The design document (docs/KNIRVHASHER_Implementation.md:§3.2) specifies the intended implementation:

// DESIGN-INTENDED IMPLEMENTATION (from docs/KNIRVHASHER_Implementation.md:449-484)
func (e *NRVEncoder) Run(ctx context.Context) error {
    stream, err := e.db.Collection("miner_processed").FlightStream(ctx)
    if err != nil {
        return fmt.Errorf("open miner_processed flight stream: %w", err)
    }
    for entry := range stream {
        arrowPath, _ := entry.Payload["arrow_path"].(string)
        records, err := loadArrowBatch(arrowPath)
        // ... encode each record via TensorPacker.Orchestrate ...
        // ... write bracket via NRVWriter.WriteBracket ...
    }
    return nil
}

Key gaps:

  • The knirvbase.Collection interface (defined in packages/KNIRVBASE/pkg/knirvbase/knirvbase.go:124–133) does not currently expose a FlightStream method. It exposes Insert, Find, FindAll, Update, Delete, AttachToNetwork, DetachFromNetwork, and ForceSync.
  • The Flight functionality lives in KNIRVBASE’s internal packages (internal/network/flight_server.go), not in the public Collection interface.
  • loadArrowBatch does not exist yet. The current arrow_writer.go writes file-based .arrow IPC (to disk), but the encoder needs to mmap + read them back.

4.2 Dependency Chain Breakage

The current 1_DATA_MINER/internal/app/miner_app.go’s MinerApp.Run() is file-based (globs *.md from a local directory, writes .arrow files to a local directory). It does not write to the miner_processed KNIRVBASE collection; there is no Flight stream between the miner and the encoder.

Mismatch: The encoder assumes data arrives via KNIRVBASE Flight (collections + streaming), but the miner writes flat files to disk. The two stages have incompatible data transfer mechanisms.

As a result, even if the Flight client were implemented in nrv_encoder.go, it would open a stream to miner_processed and immediately receive a closed/empty stream because no data was ever inserted into that collection.

4.3 Resource Contention

All pipeline stages share a single knirvbase.DB instance (per the architecture decision in docs/KNIRVHASHER_Implementation.md line 28: “all pipeline stages share the same db handle”). If 1_DATA_MINER and 2_DATA_ENCODER ever run concurrently:

  • The miner may hold a lock on the miner_processed storage while writing .arrow files
  • The encoder’s Flight stream initialization may attempt to read partially-written data
  • No atomic signal exists to indicate “all .arrow files written and registered”

While the current pipeline is sequential (one stage at a time), the design explicitly allows parallel phases within a job. This contention becomes a real risk once parallelism is enabled.

5.1.1 Replace the NRVEncoder.Run() stub

// ── nrv_encoder.go ──
package encoder

import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/apache/arrow/go/v14/arrow"
    "github.com/apache/arrow/go/v14/arrow/ipc"
    "github.com/apache/arrow/go/v14/arrow/memory"
    "github.com/apache/arrow/go/v14/arrow/array"
    "github.com/knirvcorp/knirvbase/pkg/knirvbase"

    "data-encoder/internal"
    "data-encoder/internal/writer"
)

// Run opens a Flight stream on the miner_processed collection, reads each
// .arrow file path from entry metadata, memory-maps the IPC file, and
// encodes every SecurityRecord row into a .nrv Bracket via NRVWriter.
func (e *NRVEncoder) Run(ctx context.Context) error {
    // 1. Open the collection in streaming mode
    //    (Fallback: if FlightStream is not available on Collection interface,
    //     use the underlying NRVStorage/Dataset directly.)
    coll := e.db.Collection("miner_processed")

    // 2. List all entries to discover .arrow file paths
    //    (The miner registers each .arrow file path as a doc in miner_processed
    //     with payload: {"arrow_path": "/path/to/doc.arrow"})
    entries, err := coll.FindAll(ctx)
    if err != nil {
        return fmt.Errorf("list miner_processed entries: %w", err)
    }
    if len(entries) == 0 {
        return fmt.Errorf("miner_processed collection is empty: no .arrow files found")
    }

    // 3. For each entry, locate and mmap the .arrow file
    for _, entry := range entries {
        if err := ctx.Err(); err != nil {
            return err
        }

        payload, ok := entry["payload"].(map[string]interface{})
        if !ok {
            log.Printf("nrv_encoder: entry %v has no payload, skipping", entry["id"])
            continue
        }
        arrowPath, ok := payload["arrow_path"].(string)
        if !ok || arrowPath == "" {
            log.Printf("nrv_encoder: entry %v has no arrow_path, skipping", entry["id"])
            continue
        }

        records, err := loadArrowBatch(arrowPath)
        if err != nil {
            log.Printf("nrv_encoder: load %s: %v", arrowPath, err)
            continue
        }

        // 4. Encode each SecurityRecord into a 12-slot bracket
        for i, rec := range records {
            slots := e.packer.Orchestrate(rec.ToSlotVector(), uint16(i), rec.DomainSig)
            bracket := &knirvbase.Bracket{
                Projections:   internal.SlotsToProjections(slots[:4]),
                SyntacticByte: uint8(slots[4] & 0xFF),
                DepHead:       uint8(slots[5]),
                IntentFlags:   uint8(slots[9]),
                DomainSig:     uint16(slots[10]),
                ContextMemory: internal.Slots6to8(slots[6:9]),
                GoldenSeed:    slots[11],
            }
            if err := e.writer.WriteBracket(bracket); err != nil {
                log.Printf("nrv_encoder: write bracket %d: %v", i, err)
            }
        }
    }

    log.Printf("nrv_encoder: completed, processed %d entries", len(entries))
    return nil
}

// loadArrowBatch opens an Arrow IPC file at path, reads all SecurityRecords,
// and returns them. Uses os.Mmap for zero-copy where available.
func loadArrowBatch(path string) ([]*internal.SecurityRecord, error) {
    f, err := os.Open(path)
    if err != nil {
        return nil, fmt.Errorf("open arrow file: %w", err)
    }
    defer f.Close()

    reader, err := ipc.NewFileReader(f)
    if err != nil {
        return nil, fmt.Errorf("new arrow reader: %w", err)
    }
    defer reader.Close()

    schema := reader.Schema()
    colIndex := make(map[string]int)
    for i, field := range schema.Fields() {
        colIndex[field.Name] = i
    }

    var records []*internal.SecurityRecord

    for i := 0; i < int(reader.NumRecords()); i++ {
        rec, err := reader.Record(i)
        if err != nil || rec == nil {
            break
        }
        for row := 0; row < int(rec.NumRows()); row++ {
            sr := &internal.SecurityRecord{}
            if idx, ok := colIndex["file_name"]; ok {
                if col := rec.Column(idx); col != nil {
                    if arr, ok := col.(*array.String); ok {
                        sr.FileName = arr.Value(row)
                    }
                }
            }
            if idx, ok := colIndex["chunk_id"]; ok {
                if col := rec.Column(idx); col != nil {
                    if arr, ok := col.(*array.Int32); ok {
                        sr.ChunkID = arr.Value(row)
                    }
                }
            }
            if idx, ok := colIndex["domain_sig"]; ok {
                if col := rec.Column(idx); col != nil {
                    if arr, ok := col.(*array.Uint32); ok {
                        sr.DomainSig = uint16(arr.Value(row))
                    }
                }
            }
            records = append(records, sr)
        }
    }

    if len(records) == 0 {
        return nil, fmt.Errorf("no SecurityRecords found in %s", path)
    }
    return records, nil
}

5.2 — Add Readiness Probes P0

Files affected:

  • pipeline/2_DATA_ENCODER/internal/encoder/nrv_encoder.go

Add a WaitForCollection method that polls miner_processed until it contains entries, following the established WaitForChromemDB pattern from the codebase.

// ── nrv_encoder.go (addition) ──

// defaultPollInterval is how often we check for collection readiness.
const defaultPollInterval = 500 * time.Millisecond

// defaultWaitTimeout is the maximum time we wait for the collection to be ready.
const defaultWaitTimeout = 5 * time.Minute

// WaitForCollectionReady polls the miner_processed collection until it contains
// entries or the context is cancelled. Returns the number of entries found.
func WaitForCollectionReady(ctx context.Context, coll knirvbase.Collection) (int, error) {
    deadline, cancel := context.WithTimeout(ctx, defaultWaitTimeout)
    defer cancel()

    ticker := time.NewTicker(defaultPollInterval)
    defer ticker.Stop()

    for {
        select {
        case <-deadline.Done():
            return 0, fmt.Errorf("timeout waiting for miner_processed: %w", deadline.Err())
        case <-ticker.C:
            entries, err := coll.FindAll(ctx)
            if err != nil {
                // Transient error — keep polling
                log.Printf("readiness: transient error on FindAll: %v", err)
                continue
            }
            if len(entries) > 0 {
                log.Printf("readiness: miner_processed ready with %d entries", len(entries))
                return len(entries), nil
            }
            log.Printf("readiness: miner_processed empty, retrying...")
        }
    }
}

Integrate into Run() at the top:

func (e *NRVEncoder) Run(ctx context.Context) error {
    coll := e.db.Collection("miner_processed")
    count, err := WaitForCollectionReady(ctx, coll)
    if err != nil {
        return fmt.Errorf("encoder aborted: %w", err)
    }
    log.Printf("nrv_encoder: collection ready with %d entries, starting encode", count)
    // ... rest of Run() as in §5.1.1

5.3 — Implement Exponential Backoff/Retry P1

Files affected:

  • pipeline/2_DATA_ENCODER/internal/encoder/nrv_encoder.go (new: retry.go)

Add a reusable retry helper, copied from the codebase’s established APIClient pattern (packages/KNIRVCHAIN/internal/resilience/api_client.go):

// ── nrv_encoder.go (addition) ──

const (
    maxRetries    = 5
    baseBackoff   = 100 * time.Millisecond
    maxBackoff    = 30 * time.Second
)

// retryWithBackoff executes fn up to maxRetries times with exponential backoff.
// Returns the first nil error, or the last error if all retries are exhausted.
func retryWithBackoff(ctx context.Context, fn func() error) error {
    var lastErr error
    for attempt := 0; attempt <= maxRetries; attempt++ {
        if attempt > 0 {
            backoff := time.Duration(math.Pow(2, float64(attempt))) * baseBackoff
            if backoff > maxBackoff {
                backoff = maxBackoff
            }
            log.Printf("retry: attempt %d/%d, backing off %v", attempt, maxRetries, backoff)
            select {
            case <-time.After(backoff):
            case <-ctx.Done():
                return fmt.Errorf("retry cancelled: %w", ctx.Err())
            }
        }
        if err := fn(); err != nil {
            lastErr = err
            log.Printf("retry: attempt %d failed: %v", attempt, err)
            continue
        }
        return nil
    }
    return fmt.Errorf("all %d retries failed: %w", maxRetries, lastErr)
}

Wrap the two risky operations in Run():

// In Run():
if err := retryWithBackoff(ctx, func() error {
    entries, err = coll.FindAll(ctx)
    return err
}); err != nil {
    return fmt.Errorf("FindAll after retries: %w", err)
}

// Per-file processing with retry:
for _, entry := range entries {
    arrowPath, _ := entry.Payload["arrow_path"].(string)
    var records []*internal.SecurityRecord
    if err := retryWithBackoff(ctx, func() error {
        var loadErr error
        records, loadErr = loadArrowBatch(arrowPath)
        return loadErr
    }); err != nil {
        log.Printf("nrv_encoder: skipping %s after retries: %v", arrowPath, err)
        continue
    }
    // ... encode records ...
}

func (w *ArrowWriter) WriteBatch(docID string, records []*normalizer.SecurityRecord) error {
    // ... existing file-writing logic (unchanged) ...

    // AFTER writing the .arrow file, register with KNIRVBASE if available
    if w.knirvColl != nil {
        _, err := w.knirvColl.Insert(context.Background(), map[string]interface{}{
            "id":       docID,
            "ready":    true,
            "payload":  map[string]interface{}{

        }
    }
    return nil

func extractDomainSig(records []*normalizer.SecurityRecord) uint32 {
    if len(records) == 0 {
        return 0
    }
    return uint32(records[0].DomainSig)
}

8. Rollback & Recovery

8.1 Revert Strategy

If the fix introduces a regression:

git revert --no-commit HEAD~8..HEAD
git commit -m "revert: knirvhasher nrv_encoder flight stream implementation"

All changes are scoped to packages/KNIRVHASHER/pipeline/ and have zero cross-package import dependencies, so reverting is safe and isolated.

8.2 Known Risks

RiskMitigation
knirvbase.Collection.FindAll signature mismatch (context vs no-context) Check v1.0.7 API at build time. If FindAll(context.Context) is not available, use the no-context overload or upgrade the dependency.
Large .arrow files may exhaust memory loadArrowBatch should implement a streaming reader (not NewFileReader) for files exceeding MaxArrowFileBytes (default 256MB). Add --max-arrow-bytes CLI flag.
Encoder reads partially-written .arrow file Phase 4's atomic ready flag prevents this. Miner sets ready: true only after f.Close() succeeds.
Multiple encoder instances race on same collection The current design is single-instance per node. Add processing.lock file or process-level mutex when parallelism is enabled.
NRVKnowledgeBase and FlashSearchHelper are still stubs These are downstream of this fix. The encoder currently calls packer.Orchestrate() which uses them; they return 0 and 0, producing valid but non-jittered brackets. This is acceptable for the P0 fix.
