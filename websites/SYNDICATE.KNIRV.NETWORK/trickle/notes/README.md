# KNIRV ARENA

KNIRV Arena is a landing page built for a distributed risk syndicate platform for bug bounties. The platform replaces gut-feel flat bounties with automated payouts priced dynamically via smart contracts and eBPF telemetry data.

## Features
- **Actuarial Bug Bounty:** Payouts based on actual risk scores.
- **Dynamic Pricing:** Smart contracts handle negotiations automatically.
- **Target Audience:** Cyber insurance carriers, quant hedge funds, and elite researchers.
- **Vulnerability Submission Portal:** A dedicated page for researchers to submit PoCs with real-time actuarial payout simulation.

## Design
- **Theme:** Dark Navy Blue background, Black accents, White text, and Baby Blue highlights. (Strictly no purple!)
- **Tech Stack:** React 18, TailwindCSS, Lucide Icons.
