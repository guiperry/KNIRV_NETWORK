# KNIRV Syndicate

KNIRV Syndicate is a landing page for the unified bounty pipeline. It surfaces backend-owned code-error and security-exploit postings, and directs enterprises to WebGUI and developers to KNIRVARENA.

## Features
- **Actuarial Bug Bounty:** Payouts based on actual risk scores.
- **Dynamic Pricing:** Smart contracts handle negotiations automatically.
- **Target Audience:** Cyber insurance carriers, quant hedge funds, and elite researchers.
- **Vulnerability submission:** WebGUI is the authenticated enterprise submission surface. This landing site never simulates pricing.

## Design
- **Theme:** Dark Navy Blue background, Black accents, White text, and Baby Blue highlights. (Strictly no purple!)
- **Tech Stack:** React 18, TailwindCSS, Lucide Icons.
