? What is KNIRVSERVER

KNIRVSERVER is the operator node in a sovereign AI execution network. It provides Deterministic Validation Environments (DVEs) — sandboxed, monitored, reproducible containers where AI agents execute with kernel-level behavioral tracing and policy enforcement.

MLOps teams building with LangChain, LlamaIndex, or raw API calls have no deterministic execution environment. They get flaky outputs, untracked side effects, and no forensics when something goes wrong. KNIRVSERVER's DVE + eBPF + guardrails stack offers a runtime where AI agents execute in sandboxed, monitored, reproducible containers with full behavioral tracing.

The full stack — eBPF syscall telemetry, Cognitive Engine learning loop, WASM plugin runtime, policy-to-blockchain anchoring — is a coherent protocol, not just a product. Operators connect existing hardware (old Bitcoin miners, GPU rigs, x86 servers) to earn NRN tokens for providing containerized compute to the network.

? What is KNIRVSERVER

KNIRVSERVER is a Deterministic AI Agent Runtime — sandboxed, monitored, reproducible DVE (Deterministic Validation Environment) containers with kernel-level behavioral tracing via eBPF. It ensures every AI agent execution is recorded, verified, and auditable, with policy enforcement backed by blockchain audit trails.

? How do I earn NRN tokens

Connect your old Bitcoin miners, GPU rigs, or x86 servers as DVE operator nodes. Each containerized compute task executed on your hardware earns NRN tokens. No specialized hardware required — anything that runs containers can participate.

? What is the KNIRV Network

The KNIRV Network is a Decentralized Trusted Execution Network (D-TEN) where operators provide DVE compute capacity, AI developers deploy deterministic agent runtimes, and the collective validates execution integrity via blockchain-anchored proofs.

? What are the three products

KNIRVSERVER DVE (core runtime), KNIRVCLI (command-line tool for managing DVE containers and agents), and KNIRVCONTROLLER (orchestration layer for managing node fleets). All supporting components (blockchain, graph database, gateway, testnet, etc.) are bundled within KNIRVSERVER.

? What is a DVE container

A DVE (Deterministic Validation Environment) is a sandboxed container runtime with kernel-level behavioral tracing via eBPF. Every system call, memory access, and network operation is recorded and verified. Executions produce cryptographic proofs via the CLEAN paradigm.

? How does KNIRVCLI work

KNIRVCLI is the command-line interface for deploying AI agents into DVE containers, configuring execution policies, writing agent manifests, and managing your operator node. It provides the developer workflow for the KNIRVSERVER ecosystem.

? What does KNIRVCONTROLLER do

KNIRVCONTROLLER is the mobile interface for the KNIRV Network. Manage your personal assets — wallets, NRN balances, agent deployments — and monitor network health from your phone or tablet. Includes wallet management, personal asset oversight, agent deployment, and real-time monitoring, all optimized for mobile use.

? Can I connect my old Bitcoin miner

Yes. Old Bitcoin miners, GPU rigs, and standard x86 servers can all participate as DVE operator nodes. Any hardware capable of running containerized workloads can earn NRN tokens by providing compute time to the network.

? How do NRN token economics work

NRN tokens are earned by DVE operators for executing containerized AI agent workloads. Developers pay NRN to deploy agents in DVE environments. This creates a balanced economy where compute providers earn tokens and developers pay for verifiable execution.

? Do I need specialized hardware

No. Any x86 server, GPU rig, or even a repurposed Bitcoin mining rig can participate as long as it can run containers. The KNIRVSERVER runtime is designed to make use of whatever compute capacity you have available.

? How do I deploy AI agents on KNIRVSERVER

Use KNIRVCLI to write agent manifests and deploy them into DVE containers. Each deployment creates a sandboxed, kernel-traced execution environment. Agents run deterministically with full audit trails via the CLEAN cryptographic paradigm.

? What is eBPF behavioral tracing

eBPF (extended Berkeley Packet Filter) allows kernel-level observation of every system call, memory access, and network operation made by an AI agent inside a DVE container. This produces a complete, verifiable record of agent behavior for audit and debugging.

? How do I get started developing

Self-host KNIRVSERVER via the GitHub repository or access the managed cloud DVE at knirv.com. Install KNIRVCLI, write your first agent manifest, and deploy into a DVE container. Full documentation is available on GitHub.

? What is the CLEAN paradigm

CLEAN (Cryptographic Ledger for Execution, Attestation, and Notarization) ensures every DVE execution produces cryptographic proofs that can be verified on-chain. This creates an immutable audit trail for every AI agent action.
