DVE Pod

DESIGN DECISION

Why This Approach

Three candidate designs were evaluated. The chosen approach — a WASI-native WASM module with a browser JS host and optional CLI runtime — wins on every axis.

✓

DVE Pod via KNIRVSHELL (chosen)

TinyGo → WASM/WASI binary embedded inside the knirv CLI. KNIRVSHELL auto-detects or installs a WASM runtime, then exposes clean knirv dve pod commands — no runtime plumbing visible to the user.

✗

iFrame Proxy

iFrame into a remote KNIRVSERVER DVE. Simple but requires constant network, exposes server URL, no offline capability, no portability — just a thin wrapper.

✗

Full Go WASM Bundle

Compile entire KNIRVSERVER stack to WASM. Binary would be 40MB+, Go WASM runtime overhead is severe, and most server logic (eBPF, SGX, P2P) can't run client-side.

CLI
KNIRVSHELL (knirv) — Entry Point
The knirv binary embeds dvepod.wasm via //go:embed. On first knirv dve pod call, it checks for Wasmer/Wasmtime in PATH; if absent, auto-downloads and installs Wasmer. All WASM runtime invocations are internal — users only see knirv commands.
primary entry point
L0
WASM Core — Solo Mode
TinyGo-compiled WASM module extracted from the knirv binary at runtime. BusyBox tools, shell parser, KNIRVAGENT logic, TEE simulation. No network required. Runs offline.
always available
L1
Browser Host — HTML Bundle Mode
knirv dve pod bundle generates a self-contained HTML file with the WASM binary base64-inlined. JavaScript WASI shim maps syscalls → WebCrypto, OPFS, xterm.js. Opens in any browser, no server needed.
browser runtime
L2
KNIRVSERVER Bridge — Full DVE Mode
knirv dve pod dock <url> opens a WebSocket tunnel to /ws/dve/{nodeId}/agent. Inherits full KNIRVAGENT, inner sessions, hardware TEE attestation, on-chain session binding.
optional, requires network
SYSTEM DESIGN

Architecture

KNIRVSHELL is the distribution vehicle. The knirv binary carries dvepod.wasm inside it, manages the WASM runtime lifecycle, and surfaces clean knirv dve pod subcommands. The WASM core itself is host-agnostic — the same binary also powers the browser HTML bundle.

CODE SPECIFICATION

Implementation

Five subsystems compose the DVE Pod. KNIRVSHELL is the host and distributor; the WASM core, JS bridge, TEE layer, and storage layer are all portable across runtimes.

// Run browser: open dvepod.html
// Run CLI:     wasmer run dvepod.wasm

package main

import (
    "bufio"
    "fmt"
    "os"
    "strings"

    "github.com/knirv/dvepod/internal/agent"
    "github.com/knirv/dvepod/internal/shell"
    "github.com/knirv/dvepod/internal/tee"
    "github.com/knirv/dvepod/internal/tools"
)

func main() {
    ctx, _ := tee.NewContext()    // generates P-256 identity, measures WASM hash
    bb  := tools.NewBusyBox(ctx)   // registers 20+ BusyBox commands
    ag  := agent.New(ctx)           // KNIRVAGENT: solo by default, upgrades on dock
    sh  := shell.New(ctx, bb, ag)   // line-editing shell with history

    sh.Boot()                        // print boot banner, perform self-attestation

    scanner := bufio.NewScanner(os.Stdin)
    for {
        fmt.Fprint(os.Stdout, sh.Prompt())
        if !scanner.Scan() { break }
        sh.Exec(scanner.Text())
    }
}

// internal/shell/shell.go — command dispatcher
type Shell struct {
    ctx     *tee.Context
    bb      *tools.BusyBox
    agent   *agent.KNIRVAgent
    cwd     string
    history []string
    env     map[string]string
    mode    string   // "solo" | "tethered" | "bridged"
    dockURL string
}

func (s *Shell) Exec(line string) {
    line = strings.TrimSpace(line)
    if line == "" { return }
    s.history = append(s.history, line)

    parts := shell.ParseLine(line)    // handles quotes, escapes, pipes
    cmd, args := parts[0], parts[1:]

    switch cmd {
    // BusyBox built-ins
    case "ls", "cat", "echo", "mkdir", "rm", "cp", "mv",
         "env", "pwd", "ps", "curl", "grep", "wc", "find",
         "chmod", "whoami", "date", "df", "free", "uname":
        out, err := s.bb.Run(cmd, args, s.cwd, s.env)
        s.print(out, err)

    // DVE-specific commands
    case "tee":   s.cmdTEE(args)
    case "agent": s.cmdAgent(args)
    case "dock":  s.cmdDock(args)
    case "net":   s.cmdNet(args)
    case "nrn":   s.cmdNRN(args)
    case "export":s.cmdExport(args)
    case "help":  s.cmdHelp()
    case "clear": fmt.Print("\033[2J\033[H")
    default:
        fmt.Fprintf(os.Stderr, "dvepod: %s: command not found\n", cmd)
    }
}

func (s *Shell) cmdDock(args []string) {
    if len(args) == 0 {
        fmt.Println("usage: dock <knirvserver-url> [--node-id <id>]")
        return
    }
    s.dockURL = args[0]
    s.agent.SetEndpoint(s.dockURL)   // upgrades from solo → tethered
    s.mode = "tethered"

    // Present our attestation to the server, get a chain session ID
    att, _ := s.ctx.Attest()
    sid, err := s.agent.Register(att)
    if err != nil {
        fmt.Printf("\033[31m✗ dock failed: %v\033[0m\n", err)
        return
    }
    s.env["CHAIN_SESSION_ID"] = sid
    s.mode = "bridged"
    fmt.Printf("\033[32m✓ docked to %s (session: %s)\033[0m\n", args[0], sid[:12])
}
// dvepod-host.js — WASI browser host (inlined in dvepod.html)
// Bridges WASM WASI syscalls to browser APIs.

class DVEPodHost {
  constructor(terminal) {
    this.term     = terminal;        // xterm.js Terminal instance
    this.opfs     = null;            // Origin Private File System root
    this.stdinBuf = '';             // line buffer from xterm input
    this.stdinRes = null;           // pending stdin Promise resolver
    this.decoder  = new TextDecoder();
    this.encoder  = new TextEncoder();
  }

  async init() {
    // Acquire OPFS root — persistent, quota-managed, sandboxed
    this.opfs = await navigator.storage.getDirectory();
    await this.ensureDir('home/dvepod');
    await this.ensureDir('home/dvepod/.knirv');
    await this.ensureDir('home/dvepod/workspace');
    await this.ensureDir('var/run/knirv');
    await this.ensureDir('tmp');

    return this.wasiImports();     // pass to WebAssembly.instantiate
  }

  wasiImports() {
    return {
      wasi_snapshot_preview1: {
        // stdout → xterm.js
        fd_write: (fd, iovs, iovsLen, nwritten) => {
          if (fd !== 1 && fd !== 2) return 8;
          const view = new DataView(this.memory.buffer);
          let written = 0;
          for (let i = 0; i < iovsLen; i++) {
            const ptr = view.getUint32(iovs + i * 8, true);
            const len = view.getUint32(iovs + i * 8 + 4, true);
            const bytes = new Uint8Array(this.memory.buffer, ptr, len);
            this.term.write(this.decoder.decode(bytes));
            written += len;
          }
          view.setUint32(nwritten, written, true);
          return 0;
        },

        // stdin ← xterm.js keystrokes (line-buffered)
        fd_read: (fd, iovs, iovsLen, nread) => {
          // Returns EAGAIN; real input pumped via SharedArrayBuffer or postMessage
          return 6; // EAGAIN — async model handled via Atomics.wait
        },

        // OPFS-backed filesystem ops
        path_open:   (...args) => this.opfsOpen(...args),
        fd_close:    (fd)      => this.opfsClose(fd),
        path_create_directory: (...a) => this.opfsMkdir(...a),
        path_filestat_get:     (...a) => this.opfsStat(...a),

        // Environment
        environ_sizes_get: (countPtr, sizePtr) => this.envSizes(countPtr, sizePtr),
        environ_get: (envPtr, bufPtr)           => this.envGet(envPtr, bufPtr),

        // Randomness (WebCrypto → WASM)
        random_get: (bufPtr, bufLen) => {
          const buf = new Uint8Array(this.memory.buffer, bufPtr, bufLen);
          crypto.getRandomValues(buf);
          return 0;
        },

        proc_exit: (code) => { throw new WebAssembly.RuntimeError(`exit(${code})`); },
        clock_time_get: (id, prec, timePtr) => {
          const view = new DataView(this.memory.buffer);
          view.setBigUint64(timePtr, BigInt(Date.now()) * 1000000n, true);
          return 0;
        },
      }
    };
  }

  // Feed xterm keystrokes into WASM stdin via SharedArrayBuffer
  feedStdin(data) {
    this.stdinBuf += data;
    if (this.stdinRes && this.stdinBuf.includes('\n')) {
      const res = this.stdinRes;
      this.stdinRes = null;
      res();
    }
  }
}
// internal/tee/tee.go — TEE simulation layer
// Browser mode:  P-256 keypair via WebCrypto (WASM interop call)
// SGX mode:      real quote generation via go-sgx-quote library
// SNP mode:      AMD SEV attestation via /dev/sev-guest
// Wasmer mode:   software attestation (WASM binary hash + host fingerprint)

package tee

import (
    "crypto/rand"
    "crypto/sha256"
    "encoding/hex"
    "encoding/json"
    "os"
    "time"
)

type Context struct {
    NodeID      string    `json:"node_id"`
    TEEType     string    `json:"tee_type"`      // browser-wasm|wasmer|sgx|sev-snp|tdx
    WASMHash    string    `json:"wasm_hash"`     // SHA-256 of this exact binary
    PublicKey   []byte    `json:"public_key"`
    Measurement string    `json:"measurement"`   // TEE PCR equivalent
    CreatedAt   time.Time `json:"created_at"`
}

func NewContext() (*Context, error) {
    // Measure this WASM binary — proves integrity of the runtime
    wasmBytes, _ := os.ReadFile("/proc/self/exe")
    hash := sha256.Sum256(wasmBytes)

    // Generate ephemeral identity or load persisted keypair
    nodeIDBytes := make([]byte, 16)
    rand.Read(nodeIDBytes)

    ctx := &Context{
        NodeID:      "dvepod-" + hex.EncodeToString(nodeIDBytes[:8]),
        TEEType:     detectTEEType(),
        WASMHash:    hex.EncodeToString(hash[:]),
        Measurement: deriveMeasurement(hash[:]),
        CreatedAt:   time.Now(),
    }
    ctx.PublicKey = generateOrLoadKey(ctx.NodeID)
    return ctx, nil
}

func (c *Context) Attest() (Attestation, error) {
    payload := map[string]interface{}{
        "node_id":     c.NodeID,
        "tee_type":    c.TEEType,
        "wasm_hash":   c.WASMHash,
        "measurement": c.Measurement,
        "public_key":  hex.EncodeToString(c.PublicKey),
        "timestamp":   time.Now().Unix(),
        "version":     "dvepod/1.0",
    }
    data, _ := json.Marshal(payload)
    sig := sign(data, c.NodeID)   // ECDSA P-256 signature via JS interop (browser)
                                    // or crypto/ecdsa (WASI CLI)
    return Attestation{Payload: payload, Signature: sig}, nil
}

// Server-side verification: packages/KNIRVSERVER/backend/internal/web/dve_pod_handler.go
// POST /api/dve/pod/register  →  validates attestation, creates lightweight DVECreation
func VerifyPodAttestation(att Attestation) error {
    // 1. Verify signature against claimed public key
    // 2. Check wasm_hash against known good hashes (registry)
    // 3. For tee_type=sgx: forward to Intel Attestation Service
    // 4. For tee_type=browser-wasm: accept with reduced trust level (L1 only)
    // 5. Issue chain session ID → return to pod
    return verifyECDSA(att.Payload, att.Signature)
}
// Storage architecture: three-tier persistence
//
// Tier 1: OPFS (Origin Private File System)
//   - Exposed to WASM as virtual WASI filesystem
//   - Persistent across browser sessions, up to browser storage quota
//   - Directory: /home/dvepod/, /var/run/knirv/, /tmp/
//   - Used for: workspace files, config, agent artifacts
//
// Tier 2: IndexedDB (structured data)
//   - Command history, agent chat history, session metadata
//   - Key: dvepod-{nodeId}-{table}
//   - Not exposed to WASM directly; accessed via JS bridge call
//
// Tier 3: In-memory (WASM linear memory)
//   - Active process state, environment variables, pipe buffers
//   - Lost on page reload; bootstrapped from Tier 1 on startup

// internal/storage/storage.go — WASI filesystem operations
package storage

import (
    "encoding/json"
    "os"
    "path/filepath"
)

const BaseDir = "/home/dvepod/.knirv"

func SaveIdentity(nodeID string, pubKey []byte) error {
    path := filepath.Join(BaseDir, "identity.json")
    data, _ := json.Marshal(map[string]interface{}{
        "node_id":    nodeID,
        "public_key": pubKey,
        "created_at": nowISO(),
    })
    return os.WriteFile(path, data, 0600)
}

func SaveAttestation(att interface{}) error {
    path := filepath.Join(BaseDir, "attestation.json")
    data, _ := json.MarshalIndent(att, "", "  ")
    return os.WriteFile(path, data, 0644)
}

func SaveSession(chainSessionID string) error {
    path := filepath.Join(BaseDir, "session.json")
    data, _ := json.Marshal(map[string]string{
        "chain_session_id": chainSessionID,
        "saved_at":         nowISO(),
    })
    return os.WriteFile(path, data, 0600)
}

// Encrypted export: packages entire OPFS tree as AES-256-GCM encrypted tarball
// Key derived from pod's P-256 private key via ECDH + HKDF
// Allows moving a DVE Pod to a new browser / machine
func ExportPod(nodeID, destPath string) error {
    // 1. tar -czf /tmp/dvepod-export.tar.gz /home/dvepod/
    // 2. Encrypt with AES-256-GCM using pod's derived key
    // 3. Write to destPath + print decryption instructions
    return encryptedTar(BaseDir, destPath, nodeID)
}

package dvepod

import (
    _ "embed"
    "fmt"
    "os"
    "os/exec"
    "path/filepath"
    "runtime"
)

//go:embed dvepod.wasm
var embeddedWASM []byte   // the entire dvepod.wasm binary, baked into knirv at build time

type Manager struct {
    runtimePath string   // absolute path to wasmer or wasmtime binary
    runtimeName string   // "wasmer" | "wasmtime" | "wasmedge"
    dataDir     string   // ~/.local/share/knirv/dvepod/
}

func NewManager() (*Manager, error) {
    m := &Manager{dataDir: defaultDataDir()}

    // 1. Look for runtime in PATH (prefer wasmer, then wasmtime, then wasmedge)
    for _, name := range []string{"wasmer", "wasmtime", "wasmedge"} {
        if p, err := exec.LookPath(name); err == nil {
            m.runtimePath, m.runtimeName = p, name
            return m, nil
        }
    }

    // 2. Check knirv's own data dir (previously auto-installed)
    managed := filepath.Join(m.dataDir, "runtime", "wasmer")
    if _, err := os.Stat(managed); err == nil {
        m.runtimePath, m.runtimeName = managed, "wasmer"
        return m, nil
    }

    // 3. Auto-install Wasmer into the knirv data dir (no sudo needed)
    fmt.Println("knirv: WASM runtime not found — installing Wasmer...")
    if err := m.installWasmer(); err != nil {
        return nil, fmt.Errorf("failed to install WASM runtime: %w", err)
    }
    m.runtimePath = managed
    m.runtimeName = "wasmer"
    fmt.Println("knirv: Wasmer installed at", managed)
    return m, nil
}

func (m *Manager) New(ctx context.Context) error {
    wasmPath, err := m.extractWASM()   // write embeddedWASM to ~/.local/share/knirv/dvepod/dvepod.wasm
    if err != nil { return err }
    return m.runInPTY(ctx, wasmPath, nil)
}

func (m *Manager) Bundle(outPath, dockURL string) error {
    html := renderHTMLTemplate(embeddedWASM, dockURL)  // base64-encodes wasm into HTML template
    return os.WriteFile(outPath, html, 0644)
}

func (m *Manager) runInPTY(ctx context.Context, wasmPath string, extraArgs []string) error {
    var args []string
    switch m.runtimeName {
    case "wasmer":
        args = append([]string{"run", wasmPath, "--"}, extraArgs...)
    case "wasmtime":
        args = append([]string{wasmPath, "--"}, extraArgs...)
    case "wasmedge":
        args = append([]string{wasmPath}, extraArgs...)
    }
    cmd := exec.CommandContext(ctx, m.runtimePath, args...)
    cmd.Stdin, cmd.Stdout, cmd.Stderr = os.Stdin, os.Stdout, os.Stderr
    return cmd.Run()   // user interacts directly — PTY passthrough
}

func (m *Manager) installWasmer() error {
    // Download platform-specific Wasmer release from GitHub
    // Target: ~/.local/share/knirv/dvepod/runtime/wasmer
    // Uses net/http, no external tools required
    dest := filepath.Join(m.dataDir, "runtime")
    os.MkdirAll(dest, 0755)
    url := wasmerReleaseURL(runtime.GOOS, runtime.GOARCH)
    return downloadAndExtract(url, dest)
}

BUILD & DISTRIBUTION

Build Guide

The build pipeline has one rule: dvepod.wasm is compiled first, then placed into packages/KNIRVSHELL/dvepod/ where Go's //go:embed bakes it into the knirv binary at compile time. Users never interact with the WASM file directly.

Install TinyGo (build machine only)
TinyGo produces compact WASM (~3MB vs Go's ~10MB) with strong WASI support. Required only when recompiling the WASM module — not on user machines.
brew install tinygo   # macOS
apt install tinygo    # Linux (or download from tinygo.org/downloads)
# Verify: tinygo version  →  tinygo version 0.32.0+
Compile dvepod.wasm and place it for embedding
cd packages/KNIRVSHELL/dvepod
tinygo build -target=wasi \
  -opt=2 \
  -no-debug \
  -o ../dvepod.wasm \    # lands at packages/KNIRVSHELL/dvepod.wasm
  ./cmd/dvepod/

# The go:embed directive in internal/dvepod/embed.go picks it up automatically
Build KNIRVSHELL (knirv binary) — dvepod.wasm is baked in
cd packages/KNIRVSHELL
go build -o dist/knirv ./cmd/knirvchain/

# Verify the binary carries the WASM payload:
knirv dve pod status   # prints embedded WASM hash
End-user: launch a DVE Pod (no prior setup needed)
On first run, KNIRVSHELL auto-installs Wasmer into ~/.local/share/knirv/dvepod/runtime/ — no sudo, no manual steps.
# Create a new pod (runtime auto-installed if missing)
knirv dve pod new

# Resume an existing pod
knirv dve pod run --pod-id dvepod-a1b2c3d4

# List all local pods
knirv dve pod list
Generate a browser HTML bundle
No server involved — knirv reads the WASM from its own binary and produces a self-contained HTML file.
# Basic bundle
knirv dve pod bundle --output ./dvepod.html

# Pre-seed a dock URL so it connects immediately on open
knirv dve pod bundle \
  --output ./dvepod-connected.html \
  --dock-url https://knirvserver.knirv.network

open ./dvepod.html   # or share the file — fully self-contained
Dock a running pod to KNIRVSERVER
knirv dve pod dock \
  --server https://knirvserver.knirv.network \
  --auth-token $KNIRV_TOKEN

# Inside the pod shell (same effect):
dock https://knirvserver.knirv.network

Note on browser stdin: The HTML bundle's JS WASI shim needs SharedArrayBuffer for stdin, which requires Cross-Origin-Opener-Policy: same-origin + Cross-Origin-Embedder-Policy: require-corp headers. The bundler inlines a Service Worker that self-injects these for file:// use, so the HTML works without any server. When hosted on KNIRVSERVER, the headers are already present in the existing middleware.
